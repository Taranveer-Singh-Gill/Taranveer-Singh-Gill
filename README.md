### 🚀 Featured Projects

#### 🏥 Epic FHIR Cloud Lakehouse

An end-to-end healthcare data platform integrating Epic FHIR R4 APIs with Azure cloud services.

- Extracted synthetic healthcare resources using Epic FHIR APIs and OAuth 2.0.
- Implemented Bronze, Silver, and Gold data layers using Azure Databricks, PySpark, and Delta Lake.
- Developed analytics-ready healthcare datasets using Azure Synapse Serverless SQL.

**Tech:** Python, Epic FHIR R4, Azure ADLS Gen2, Databricks, PySpark, Delta Lake, Synapse SQL

[View Project →](https://github.com/Taranveer-Singh-Gill/epic-fhir-data-platform)

#### 🌍 International Trade Flow Data Platform

Built a data engineering platform to process and analyze international trade data across 40+ countries.

- Developed Python ETL pipelines to ingest and transform data from APIs, CSV, and JSON sources.
- Processed 2M+ trade records and organized commodity and industry datasets.
- Stored structured data in Azure PostgreSQL to support interactive trade flow visualizations.

**Tech:** Python, SQL, Azure PostgreSQL, ETL, Data Modeling

#### 🩺 HL7 FHIR Healthcare Data Pipeline

Developed an end-to-end ELT pipeline to transform synthetic HL7 FHIR R4 resources into analytics-ready datasets.

- Ingested FHIR Patient, Encounter, and Observation resources into PostgreSQL.
- Used dbt to transform nested healthcare data into structured relational models.
- Designed dimensional models for patient encounters, laboratory results, and vital signs.

**Tech:** Python, HL7 FHIR R4, PostgreSQL, dbt, SQL

[View Project →](https://github.com/Taranveer-Singh-Gill/fhir-project)

#### 📊 Workforce Management Database

Designed a database-driven workforce management platform focused on efficient data storage, querying, and analytics.

**Tech:** Python, SQL, Azure, Streamlit
